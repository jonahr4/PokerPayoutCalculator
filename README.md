# Poker Payout Calculator

A lightweight web app for quickly calculating tournament payouts. The goal of this project was to practice basic web development skills while building a fun, single-page poker utility.

## Live Demo

Visit the live version at [jonahrothman.com/PokerPayoutCalculator](https://jonahrothman.com/PokerPayoutCalculator/).

## Getting Started

Follow these steps to run the app locally:

1. **Clone the repository**
   ```bash
   git clone <repo-url>
   cd PokerPayoutCalculator
   ```
2. **Open the app**
   - Double-click `index.html`, or
   - Serve the project with a simple HTTP server:
     ```bash
     python3 -m http.server 8000
     ```
3. **Use the calculator**
   - Enter buy-in, rebuy, and payout structure values.
   - Review the calculated payouts instantly in your browser.
